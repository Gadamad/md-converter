# MD Converter 0.4.1

The dashboard's **Save an extra copy** option now offers **New folder inside Save to** or **Existing folder → Choose existing folder…**. The native Mac picker can select a folder you already have. Review the full path and press **Use folder** to commit it; Cancel, Escape and picker cancellation preserve the saved choice. **Change folder…** reopens both options. Regular exports remain saved in their usual location.

Existing destinations keep the same format and workbook subfolders, exact Markdown/TXT bytes, collision-safe filenames and protection for edited copies. A missing selected folder is reported without recreating it, and delivery retries reuse saved conversions and recognized image text. Each queue freezes its destination and mode. An unavailable optional folder does not block unrelated preferences. Mounted filesystem identity checks prevent an existing destination from overlapping regular exports even under differently capitalized APFS paths. Old named-folder preferences and journals retain their behavior; no database migration or dependency upgrade is required.

Validation: 699 tests and 62 subtests passed. Regression cases cover native-picker staging/cancel, mode switching, preference rollback/restart, missing-root recovery without reconversion/OCR, edited-copy preservation, frozen queue/journal destinations, symbolic-link changes and actual APFS capitalization aliases. The automated browser pass checked 48 footer layout combinations. Actual Safari checked the new dialog, path preview, Cancel/Escape and saving in an isolated preview at 640 × 640 dark and 820 × 780 light. Five existing PyMuPDF deprecation warnings remain.

The installed macOS app also passed native picker cancellation and selection, draft-only picking before Use folder, a Hungarian sample conversion and byte-identical delivery into a pre-existing folder. Its existing unrelated file was preserved. The completed conversion and existing-folder choice survived restart. Disposable QA data was removed from the active app; the original two saved queues, waiting item, active selection and preference bytes were restored exactly, with all 25 protected outputs unchanged.
