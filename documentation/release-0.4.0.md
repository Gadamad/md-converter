# MD Converter 0.4.0

The packaged macOS app was verified through its native file picker: a Hungarian EPUB produced Markdown, and a complete Project Gutenberg EPUB produced TXT. Their named-folder copies match exactly, the TXT choice survives restart, and the original books, existing completed conversion, quote exports, saved queues and preferences were verified unchanged after testing.

Add EPUB books through files, folders or drag and drop, then convert the saved queue as usual. **Preferences → EPUB output** chooses **Markdown (.md)** or **Plain text (.txt)**, with Markdown as the default. Each book becomes one file under the `epub` output folder. Chapters follow the package's declared reading order; headings, paragraphs, lists, basic tables, authors and Hungarian accents are retained. Navigation blocks, scripts and embedded images are omitted. Auxiliary and hidden footnotes remain available as text.

TXT exports contain readable text without Markdown headers or formatting markers. Named-folder copies preserve their extension and bytes. Optional Obsidian delivery remains a Markdown note. Queue items freeze the output choice when conversion starts; failed delivery reuses the private converted file even if the original book is unavailable or Preferences changes later. Existing Markdown receipts and all other source formats keep their behavior. Quoted or multiline book metadata is escaped correctly in vault frontmatter.

EPUB reading uses the existing local dependencies. It never extracts archive members, executes book code or fetches book resources. EPUB 2/3 XHTML/HTML chapters and usable XHTML fallbacks are supported. Invalid reading order, corrupt compression, encrypted selected chapters and unsupported chapter types report clear failures. Font obfuscation alone is allowed. Image-only books require OCR outside this EPUB feature. Streamed limits cover archive entry count, control XML, individual chapters and total decompressed document reads. Original books and prior conversion data are preserved; no database migration is required.

Validation: 625 tests and 62 subtests pass, including generated reading-order/Unicode invariants, EPUB 2/3 fixtures, malformed archives, DTD rejection, cancellation, TXT delivery, unchanged originals and retries without reconversion. Independent review identified corrupt-DEFLATE error handling and readable object/canvas fallback text; regression tests cover both fixes. Actual Safari verified the Preferences control, Save/Cancel and rendering at 640 × 640 and 820 × 780, with light and dark appearances, using an isolated local preview. A real [Project Gutenberg EPUB](https://www.gutenberg.org/ebooks/11) converted successfully to Markdown and TXT with matching 29,572-word counts and correct chapter order. Five existing PyMuPDF deprecation warnings remain.
