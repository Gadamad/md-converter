# MD Converter 0.3.6

Local image OCR checks anomalous Latin character runs before accepting a readable sentence. Closing quotation marks and punctuation can be misread as letter sequences; the app now tries remaining image variants and the fallback engine instead of silently accepting them. A substantially shorter fallback is kept for review rather than published as a complete quote. Both engines retain their existing deadlines.

Unresolved suspicious text appears as **Needs review**, with **Preview**, **Try again** and **Skip** available. The batch continues and the journal retains candidate text, quality reasons, engine, variant and elapsed time. Global failed-engine retries leave review decisions to the user; individual retries remain available. Legitimate Hungarian accents, Vietnamese and multilingual text are preserved. This is a conservative check for the observed corruption, not a guarantee that OCR can never misread a word.

Queues use compact rows by default. The dashboard **Show source details** checkbox shows full URLs and source paths and remembers the choice across restarts. Source details remain available on hover. Completed file entries have an **Open** action for the original file; completed websites and pasted text open their saved Markdown. Existing queue names, completed entries, folder-depth settings and recovery controls are preserved.

Source-verified quote repairs validate every original image fingerprint and saved record before changing any text. Their audit retains the original recognition in the journal, while readable Markdown omits the known-bad raw OCR for those verified quotes. Existing journals and queue databases remain compatible; no dependency updates or database migration are required. Personal images, quote data and backup files are excluded from the release and Git repository.

Validation: 449 tests and 14 subtests pass, including browser checks at the minimum window size, write-failure rollback, source/output opening, guarded repairs, OCR worker supervision and review recovery. Five existing PyMuPDF deprecation warnings remain. The guard detects all 79 audited corrupt readings. Fresh local OCR of three original affected images recovered complete clean readings through alternate variants. The source-verified repair retained all other image records and completed queue entries, original file fingerprints, accents, settings and queue names; both readable Markdown copies and their journals match.
