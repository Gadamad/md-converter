# MD Converter 0.3.7

The dashboard now offers **Save to a named folder**. Enabling it opens a folder-name dialog with a full destination preview. Finished Markdown receives an extra copy inside that named child of the current **Save to** location; the normal output remains saved. **Change name** chooses another folder, and unticking disables copies for new work. The choice is remembered across restarts.

Copies preserve the finished file's bytes, including Hungarian accents, and retain format and workbook subfolders. Existing unrelated files and edited copies are preserved through collision-safe names. Linked folders, path traversal and names that conflict with the app's primary format folders are rejected. The dialog supports cancellation, keyboard focus and failed-save rollback; controls stay aligned at the minimum window size.

Queue items retain their copy destination when work begins. Durable document receipts and image journals track reserved destinations and unfinished delivery. A failed extra copy leaves normal files and recognized image text safe; retry completes the export without repeating successful conversion or OCR. Image cancellation saves a copy of completed work, and skipping an unsuccessful image updates its final report and existing copies. Copy failures preserve image review reasons. Existing completed entries are not copied retroactively.

Validation: 511 automated tests and 47 subtests pass. Coverage includes multiple worksheet files, partial delivery, interruption after atomic replacement, retry with changed dashboard settings, edited-file preservation during delivery, image recovery, canceled pending work, skipping, old journals, destination failures, preference rollback and browser behavior at 640 × 640. Real TXT and two-sheet XLSX conversion produced three matching copies with unchanged originals. The corrected 1,356-image Markdown export also copied byte for byte; its live outputs and journals retained their hashes. Five existing PyMuPDF deprecation warnings remain. No new dependencies or queue database migration are required.
