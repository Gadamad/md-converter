# MD Converter

Register: product

A local macOS utility for turning documents, spreadsheets, web pages and quote images into readable Markdown, with optional Obsidian delivery. It serves people building a personal knowledge library, including large image collections.

The essential journey is add → review → convert → open results. A difficult image must never hold the rest of a collection hostage. Completed image results survive interruption; failures remain visible and can be retried separately.

Personality: thoughtful, precise and reassuring. Show care through readable content, predictable controls, honest progress and recoverable work. Avoid technical configuration instructions in everyday flows, crowded button strips and decorative dashboards.

The user approved resumable image batches, failed-only retry, bounded-memory spreadsheets, tested dependency updates, installation with a backup, and a thorough interface redesign on 2026-10-08.
